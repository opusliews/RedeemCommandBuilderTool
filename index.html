Channel Points Info

Channel points are available and working on all platforms (Twitch, Youtube, and Kick)

Viewers receive 5 points every 6 minutes. There are currently two redeem commands available, each costing 10 points.

The available commands are !eyes and !face. These commands require parameters and can be constructed using the tool provided on this page just below.
Simply set the desired options and click "Copy", then paste the command into the channel chat.

Other commands:
!points: Shows how many channel points you have

Eyes Instructions:

The !eyes redeem command sets the model eye colors. It follows the following structure:

!eyes <parameter>=<value> <parameter>=<value> ...

The command requires at least one parameter, but can have any combination, or all of them at once.

Values can be color or numerical.

Color values can be written as hex RGB values with or without a preceding #, or decimal (RGB) values comma separated.
Valid color examples (for red, green and blue in that order):
#FF0000
00FF00
0,0,255

List of Parameters:

Color Parameter What it changes Example
ic Iris color ic=#df6400
iec Iris effect color iec=FFD000
sc Sclera (white of the eye) color sc=ffffff
Numerical Parameter What it changes Example
ibr Iris brightness ibr=2
iebr Iris effect brightness iebr=1

Face Instructions:

The !face redeem command morphs the model's face. It follows the following structure:

!face <parameter>

List of Parameters: Momo, Nick, Nonose, Copium

All command choices:

!face momo
